Angular CRUD project / interview notes

Four questions, one working app

A standalone reference for reactive forms, component communication, multiple components on one page, and the complete UI-to-Spring-Boot flow.

1. What is a reactive form?

A model-driven form where TypeScript creates the FormGroup and FormControl instances, while the template binds to them.

tutorialForm = this.formBuilder.nonNullable.group({
  title: ['', Validators.required],
  description: ['', Validators.required]
});

2. Reactive forms vs template-driven forms?

Reactive forms keep structure and validation in TypeScript, are easier to test, and scale well. Template-driven forms use ngModel and put more behavior in HTML.

3. What is FormControl?

FormControl represents one input value, its validation state, and interaction state. This project uses one for title search.

titleControl = new FormControl('', {
  nonNullable: true
});

4. What is FormGroup?

FormGroup groups related controls and exposes aggregate value and status. The add and edit screens use a group for title and description.

5. Why use nonNullable?

It keeps control values typed as strings instead of string | null, reducing null checks in request payloads.

6. How do you bind a reactive form?

Bind the group on the form and map each input with formControlName.

<form [formGroup]="tutorialForm"
  (ngSubmit)="saveTutorial()">
  <input formControlName="title" />
</form>

7. How do you add validation?

Pass validators when creating a control. This project requires title and description with Validators.required.

8. How do you check validity?

Use form.invalid or form.valid before sending data. markAllAsTouched() shows validation state after an invalid submit.

if (this.tutorialForm.invalid) {
  this.tutorialForm.markAllAsTouched();
  return;
}

9. touched, dirty, and pristine?

touched means focus was lost, dirty means the value changed, and pristine means it has not changed. They control when errors appear.

10. setValue vs patchValue?

setValue requires every control. patchValue updates only supplied fields, which is useful after the edit API returns data.

this.tutorialForm.patchValue({
  title: data.title ?? '',
  description: data.description ?? ''
});

11. How do you reset a form?

Call reset() on the FormGroup. The Add action does this after a successful create.

12. What is FormBuilder?

FormBuilder is a factory service that reduces boilerplate when creating controls and groups.

13. How do you submit?

Use ngSubmit on the form rather than a click handler on submit. It also supports pressing Enter.

<form [formGroup]="tutorialForm"
  (ngSubmit)="updateTutorial()">
  <button type="submit">Update</button>
</form>

14. How do you read values?

Use form.value, or read a specific typed control such as tutorialForm.controls.title.value.

15. How do you create a dynamic form?

Use FormArray for a variable number of controls. This CRUD form has a fixed shape, so FormGroup is appropriate.

16. What is cross-field validation?

A validator attached to the FormGroup compares multiple controls, such as password and confirmation.

17. What are async validators?

Async validators return an Observable or Promise, for example to check a username on the server.

18. How do you disable a control?

Create it with a disabled state or call disable(). Disabled controls are excluded from form.value.

19. Which module enables reactive forms?

Import ReactiveFormsModule in the NgModule that owns components using reactive form directives.

imports: [
  BrowserModule,
  ReactiveFormsModule,
  HttpClientModule
]

20. How do you test reactive forms?

Configure ReactiveFormsModule in the test, create the component, set control values, and assert validity or the service payload.

Parent

TutorialsListComponent

Owns the list and selected item. It passes data and display mode to its child.

<app-tutorial-details
  [viewMode]="true"
  [currentTutorial]="currentTutorial">
</app-tutorial-details>
Child

TutorialDetailsComponent

Receives the selected tutorial through @Input(). It supports both view mode and routed edit mode.

@Input() viewMode = false;
@Input() currentTutorial: Tutorial = {};
Sibling routes

AddTutorialComponent

Add and list are siblings under AppComponent. They communicate through TutorialService, not by accessing each other directly.

{ path: 'add',
  component: AddTutorialComponent }
{ path: 'tutorials',
  component: TutorialsListComponent }

Interview answer

Parent-to-child communication uses @Input(). Child-to-parent communication uses @Output() and EventEmitter. Sibling components communicate through a shared service or common parent. In this app, TutorialService is the shared API boundary.

How several components appear on one page

Angular combines a persistent shell, a routed view, and nested selectors. This app renders the navbar from AppComponent, places the active route into router-outlet, and nests TutorialDetailsComponent inside TutorialsListComponent.

End-to-end: Add a tutorial

1UI

User enters title and description in AddTutorialComponent.

2Reactive form

The controls are validated before creating the request payload.

this.tutorialService.create({
  title: this.tutorialForm.controls.title.value,
  description: this.tutorialForm.controls.description.value
});
3Angular service

TutorialService sends JSON through HttpClient.

return this.http.post(
  'http://localhost:8080/api/tutorials', data
);
4Spring Boot controller

TutorialController receives the body and saves an entity through TutorialRepository.

@PostMapping("/tutorials")
public ResponseEntity<Tutorial> createTutorial(
    @RequestBody Tutorial tutorial) { ... }
5Response to UI

The Observable emits the response, submitted becomes true, and the success state is displayed.

next: (res) => {
  this.submitted = true;
}
